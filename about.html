About PseudoDojo

Welcome to the PseudoDojo website, a digital hub for pseudopotentials generated through the PseudoDojo Project .

The PseudoDojo Project

The PseudoDojo is an open-source Python framework for generating, validating, and storage of high-quality sets of pseudopotentials (or "pseudos" for short). The framework is built off the AbiPy package and supports the following seven testing workflows executed within Abinit :

  • delta-gauge;
  • revised delta gauge by Jollet et al.;
  • GBRV tests for FCC structures;
  • GBRV test for BCC structures;
  • GBRV tests for compounds;
  • phonons at the Gamma point;
  • tests for the presence of ghost-states below and above the Fermi level.

The pseudopotential repository, including previous versions of pseudopotentials, can be found on our GitHub .

Files provided

The web interface provides information through many file types:

  • .psp8: a norm-conserving (NC) pseudopotential in psp8 format (for use in Abinit )
  • .upf: a NC pseudo in upf format (for use in Quantum ESPRESSO )
  • .psml: a NC pseudo in psml format (for use in SIESTA )
  • .xml: (PAW) the paw dataset in xml format (for use in Abinit or GPAW )
  • .in: Input file used the generate the pseudopotential. For norm-conserving pseudos, this is likely an ONCVPSP input file. For JTH (PAW) pseudos, this is an atompaw input file.
  • .djrepo: a JSON document with the consolidated test report of the NC pseudo.

The Dojo Ethos

PseudoDojo is inspired by the traditional Japanese and originally Buddhist dōjō (道場), literally translated to "the place of the Way." Dojos are spaces dedicated to disciplined practice, continuous improvement, and the pursuit of mastery.

In a metaphorical capacity, we define "the way" as the PseudoDojo framework for the careful development, testing, and refinement of pseudopotentials. Inspired by this philosophy and the playful similarity of the words "pseudo" and "judo," the PseudoDojo project aims to provide a curated, rigorously validated collection of pseudopotentials together with the tools and benchmarks needed to help the electronic structure theory community achieve reliable, reproducible first-principles simulations. With our web interface, we enrich the aptitude of the dojo ethos in this context by emphasizing PseudoDojo's social function as a digital space for users of all belt ranks to train on and interact with pseudopotentials.
