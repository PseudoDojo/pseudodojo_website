Contribute

Have an idea for making better pseudos? We're always on the lookout for contributors to the PseudoDojo Project. Here's how to start.

I'd like to add new pseudo tables or sets.

If you want to generate new pseudos using the PseudoDojo framework, please visit the GitHub repository . Download the repository, and where relevant, perform the tests that are already present. Some tests, like the Delta gauge, require all-electron (AE) reference data that is only available for specific exchange-correlation functionals; others do not. More details can be found in the GitHub repository README file .

I'd like to contribute to development of the PseudoDojo framework.

We're glad to have you on board! To start, please visit the GitHub repository , fork the project, then commit your contributions accordingly.

NOTE: If you contribute new functionality (a new test, for example), please provide unit tests for your code. We cannot accept code additions without such tests.
